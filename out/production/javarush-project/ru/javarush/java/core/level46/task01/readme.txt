Волшебные данные героя 🧙‍♂️
Представьте, что вы — системный администратор в мире фэнтези, и вам нужно настроить профиль для легендарного героя "Громобой". Его данные хранятся в специальном магическом формате JSON, но кто-то случайно наложил на них заклинание, и теперь они выглядят вот так:

{
  'id': 5,
  "name": "Bob",
  "age": 30,
}
Ваша срочная задача — снять это заклинание, то есть исправить все синтаксические ошибки в этом фрагменте. Превратите его в абсолютно валидный JSON-документ, чтобы магическая система могла корректно загрузить характеристики вашего героя "Громобой" для его следующего великого приключения!

Требования:
•	Все ключи в JSON-объекте должны быть заключены в двойные кавычки ("), а не в одинарные (').
•	В конце последнего элемента объекта не должно быть запятой.
•	Общий формат объекта (фигурные скобки, разделение ключ-значение через двоеточие) должен быть сохранён.
•	Строковые значения должны быть в двойных кавычках, числовые значения — без кавычек.

{
  'id': 5,
  "name": "Bob",
  "age": 30,
}

Правильное решение

{
  "id": 5,
  "name": "Bob",
  "age": 30
}

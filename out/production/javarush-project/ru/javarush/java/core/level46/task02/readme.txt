Создание карточки для цифровой библиотеки 📚
Вы — главный библиотекарь в огромной цифровой библиотеке, и ваша задача — создавать идеальные электронные карточки для новых поступлений. Для начала, вам нужно описать одну конкретную книгу, чтобы читатели могли легко её найти.

Создайте JSON-объект, который будет служить такой карточкой, содержащей всю необходимую информацию о произведении.

В этой карточке должны быть следующие обязательные поля: "title" для названия книги, "author" для имени её создателя, "year" для даты выпуска (именно года издания) и "genres" для перечисления всех категорий, к которым относится книга.

Подумайте о вашей любимой книге и используйте её в качестве примера, создавая этот JSON-объект с корректным синтаксисом, чтобы каждый читатель мог легко найти это произведение в вашей цифровой сокровищнице знаний.

Требования:
•	Необходимо создать корректный JSON-объект, описывающий книгу.
•	В JSON-объекте должно присутствовать поле "title", содержащее строку с названием книги.
•	В JSON-объекте должно присутствовать поле "author", содержащее строку с именем автора книги.
•	В JSON-объекте должно присутствовать поле "year", содержащее число, обозначающее год издания книги.
•	В JSON-объекте должно присутствовать поле "genres", содержащее массив строк с категориями, к которым относится книга.
•	JSON-объект должен быть валидным с точки зрения синтаксиса JSON (правильные кавычки, запятые, типы данных).

данные - пустая страница

Правильное решение:

{
  "title": "Тайна старого маяка",
  "author": "Мартин Хейл",
  "year": 1967,
  "genres": ["Роман", "Сатира", "Фантастика", "Мистика"]
}
